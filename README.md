# Мої права (moyi-prava)

Сайт-навігатор для военнообязанных и их семей в Украине: что делать при остановке, проверка повестки, отсрочка, генератор жалоб, помощь родным. Весь сайт — на украинском, это README — на русском.

Стек: Node.js + Express, статические страницы, без базы данных, без внешних шрифтов и трекеров. PWA (манифест + service worker) — главный экран, «Меня остановили» и генератор жалоб работают офлайн.

## Запуск

```bash
npm install
npm run build   # собирает dist/ из content/ и src/
npm start       # http://localhost:3000 (порт из process.env.PORT)
npm test        # E2E-проверка в Chromium (нужен Playwright; сервер должен быть запущен, BASE=http://localhost:3000)
```

Папка `dist/` лежит в репозитории, поэтому Railway ничего собирать не обязан. Если `dist/` отсутствует, `server.js` соберёт её сам при старте.

## Переменные окружения

| Переменная | Для чего |
|---|---|
| `PORT` | порт (Railway задаёт сам) |
| `SITE_URL` | полный адрес сайта без `/` в конце, например `https://moyi-prava.up.railway.app` — идёт в canonical, Open Graph, sitemap.xml, robots.txt. Если не задан — берётся из запроса |
| `LAWYER_TELEGRAM_URL` | ссылка для кнопки «Написати адвокату» (`https://t.me/...`). Если не задана или неверного вида — вместо кнопки показывается номер 0 800 213 103 |

## Структура проекта

```
server.js                 Express: отдаёт dist/, sitemap.xml, robots.txt, CSP-заголовки, подставляет SITE_URL и LAWYER_TELEGRAM_URL
scripts/build.js          генератор: content/*.json + src/ → dist/ (страницы, search-index.json, sw.js)
scripts/make-images.js    разовая генерация PNG-иконок и og.png (нужен Playwright)
content/
  sources.json            список официальных источников (id → название, ссылка) и дата «Перевірено»
  situations.json         ситуации «Мене зупинили» (поліція/ТЦК/блокпост): по одной странице /sytuatsiyi/<id>/ на каждую
  faq.json                вопросы и ответы (FAQ + разметка schema.org FAQPage)
  vidstrochka-data.json   вопросы и основания навигатора отсрочек
  pages/*.json            по одному файлу на страницу (тексты)
src/
  generator.html          форма генератора жалоб (вставляется на /skarha/)
  urgent.html             форма «Терміново: передати справу юристу» (/terminovo/)
  assets/                 style.css, app.js, generator.js, vnav.js, search.js, иконки
  sw.js, manifest.webmanifest
dist/                     собранный сайт (коммитится)
tests/e2e.js              проверка страниц, ширины 360px, ссылок, генератора, навигатора, поиска, офлайна
```

## Как обновить текст страницы

1. Откройте `content/pages/<страница>.json`. Основные страницы: `mene-zupynyly` (Мене зупинили), `blokpost`, `povistka`, `perevirka-povistky`, `vidstrochka`, `skarha`, `shtraf`, `zabraly`, `dopomoha`, `pryvatnist`. FAQ — `content/faq.json`.
2. Измените текст. Поля страницы: `title`, `description` (для SEO), `h1`, `lead`, `sources` (id из `sources.json`), `blocks` (содержимое).
3. Типы блоков:
   - `{"t":"h2","x":"Заголовок"}`, `{"t":"p","x":"Текст"}`
   - `{"t":"ul","items":[...]}` — список; `{"t":"ol","items":[...]}` — шаги; `{"t":"check","items":[...]}` — чек-лист
   - `{"t":"callout","kind":"info|warn|lawyer","title":"...","x":"..."}` — выноска. `kind: "lawyer"` — плашка **«Потребує перевірки юристом»**
   - `{"t":"links","items":[{"u":"/путь/","t":"Название"}]}` — кнопки-ссылки
   - спецблоки: `vnav`, `vall` (навигатор отсрочек), `generator` (форма жалоб), `lawyer` (кнопка адвоката)
4. В тексте можно использовать `**жирный**` и `[текст](https://...)`. Партнёрская ссылка: `[текст](https://... "sponsored")` — получит `rel="sponsored"`.
5. Основания отсрочки и документы — в `content/vidstrochka-data.json` (`grounds` — основания, `questions` — вопросы и связи с основаниями).
6. Когда меняется закон: обновите текст, добавьте/поправьте источник в `sources.json` и **дату `verified`** (она выводится внизу каждой страницы как «Перевірено»).
7. Выполните `npm run build`, проверьте локально (`npm start`), затем `git add -A && git commit && git push` — Railway задеплоит сам.

### Ситуации («Меня остановили»)

Файл `content/situations.json`: `groups` — группы и порядок кнопок на `/mene-zupynyly/`; `situations` — страницы. Поля ситуации: `label` (текст кнопки), `h1`, `description`, `lead`, `do` (что делать), `dont` (чего не делать), `know` (что важно знать, с ссылками на пункты норм), `lawyer` (необязательно — плашка «Потребує перевірки юристом»), `sources` (id из `sources.json`). Чтобы добавить ситуацию — добавьте объект и его id в нужную группу, затем `npm run build`.

### Заявление об отсрочке (/zaiava-vidstrochka/)

Черновик заявления (обязательные сведения — п. 58 ПКМУ № 560; перечень документов берётся из `content/vidstrochka-data.json`, поле `docs` выбранного основания). Работает на устройстве; логика — `src/assets/zaiava.js`, форма — `src/zaiava.html`.

### Прочее

- Генератор жалоб (`/skarha/`) содержит тип «Заява про незгоду з рішенням ВЛК» (п. 72–73 ПКМУ № 560).
- `/rezerv-plus/` (что передбачено Порядком про электронный документ, QR, авто-отсрочку) и `/slovnyk/` (словарь терминов с пунктами норм) — `content/pages/`.
- `/sud/` — как оспорить действия ТЦК в суде (ст. 25, 122, 160, 161, 286 КАС; иерархия ТЦК — Положение, ПКМУ № 154). В генераторе жалоб есть тип «Позовна заява до адмінсуду», а поле «Кому» — выпадающий список адресатов с пояснением, кто «вышестоящий».
- `/dlia-rodyn/` — чек-лист «Папка документів» (`content/pages/dlia-rodyn.json`).

### Быстрая заявка юристу (/terminovo/)

Короткая форма собирает ключевые факты в сообщение (на устройстве). Кнопка Telegram открывает `LAWYER_TELEGRAM_URL`; если это ссылка вида `https://t.me/<ник>`, текст подставляется автоматически (`?text=`), иначе текст копируется — его нужно вставить в чат.

Шаблоны текстов жалоб (генератор) находятся в `src/assets/generator.js`, поля формы — в `src/generator.html`.


## Монетизация (необязательные переменные)

| Переменная | Что делает |
|---|---|
| `DONATE_URL` | `https://...` — в подвале всех страниц появляется кнопка «Підтримати проєкт» (банка Monobank, Buy Me a Coffee и т.п.). Без переменной кнопки нет |
| `LAWYER_PARTNER=on` | кнопки адвоката получают `rel="sponsored"` и на странице появляется раскрытие «Партнерське посилання…» (нужно, если адвокат платит вам за обращения) |

Рекомендация: не вставлять рекламные сети и трекеры (теряется доверие и обещание «без трекеров»). Доход — пожертвования, партнёрство с адвокатами/НКО/юрфирмами с раскрытием, платные услуги проверки документов юристом.

## Как проверить, что законы на сайте верны (без юриста)

Гарантировать «1000%» нельзя никому, но можно **механически** доказать то, что поддаётся доказательству, и честно пометить остальное.

1. **Реестр утверждений** — `content/claims.json`: каждое правовое утверждение (срок, право, обязанность, санкция) хранится с точной ссылкой (статья/пункт) и **дословной цитатой** из нормы.
2. **Автопроверка** — `npm run verify`: скачивает свежие тексты норм с zakon.rada.gov.ua (при сбое сети берёт кэш `.verify-cache/`), проверяет, что каждая цитата есть в тексте, сравнивает **дату редакции** каждого акта с записанной и проверяет, что все ссылки «п. N» в контенте существуют в указанном акте. Код выхода ≠ 0, если что-то не подтвердилось или редакция изменилась. Результат — `docs/VERIFICATION.md` и `content/verification.json`; публично он показан на странице `/pro-sait/`.
3. **Правило для новых текстов**: любое новое юридическое утверждение сначала добавляется в `claims.json` с цитатой, затем в текст. Нет цитаты — нет утверждения (или блок «Потребує перевірки юристом»).
4. **Что проверка НЕ делает**: не оценивает применение нормы к конкретному делу; не проверяет практические советы (зафиксировать, не сопротивляться); не следит за актами, которых нет в `claims.json` (Конституция, КПК, КАС, НК — они помечены «потребує перевірки»). Для них нужен юрист или добавление в реестр.
5. **Как часто**: запускайте `npm run verify` при каждом изменении текстов и по расписанию (плановая задача каждые 2 часа делает это).
6. **Если редакция акта изменилась**: прочитайте изменённые пункты в zakon.rada.gov.ua, исправьте тексты и `claims.json`, обновите `edition` в `claims.json` и дату `verified` в `content/sources.json`.

- Кнопки адвоката больше **без** `rel="sponsored"`. Если у вас есть коммерческое/партнёрское соглашение с адвокатом, укажите это на странице `/dopomoha/` и верните `sponsored` в `scripts/build.js` (блок `lawyer`) и `src/urgent.html`.
- `npm run verify -- --update-hashes` — обновляет «отпечатки» цитируемых разделов в `content/claims.json` после того, как вы перечитали изменённую норму.

## Индексация и домен

- По умолчанию сайт **закрыт от индексации** (`robots.txt: Disallow: /`, заголовок `X-Robots-Tag: noindex`, `<meta name="robots" content="noindex">`), чтобы временный адрес `*.up.railway.app` не попал в поиск.
- Когда будет домен: в Railway задайте `SITE_URL=https://ваш-домен` и `INDEXING=on`. Тогда включатся `index,follow`, `robots.txt` с `Allow` и `Sitemap`, `sitemap.xml` с `lastmod`, canonical/Open Graph на ваш домен.
- Необязательно: `REDIRECT_TO_SITE_URL=1` — 301-редирект со всех других хостов (в т.ч. railway) на `SITE_URL`. Включайте только после того, как домен подключён и работает.
- После включения: добавьте сайт в Google Search Console и Bing Webmaster Tools (подтверждение права — через DNS-запись домена), отправьте `https://ваш-домен/sitemap.xml`.
- Проверка SEO: `npm run test:seo` (нужны два сервера: с `INDEXING=on SITE_URL=https://moyi-prava.example` на порту из `BASE_ON` и без `INDEXING` на `BASE_OFF`).

## Источники и важные замечания

- Закон № 3543-XII (ст. 22, 23) и постановление КМУ № 560 от 16.05.2024 — тексты прочитаны на zakon.rada.gov.ua (редакции от 31.07.2026 и 15.08.2026).
- **Блокпосты** — постановление КМУ № 1455 от 29.12.2021; **проверка документов и осмотр вещей/транспорта** — постановление КМУ № 1456 от 29.12.2021 (оба + ст. 8 Закона «Про правовий режим воєнного стану»). Не путать с другим № 1456 от 27.12.2022 (спортивные федерации).
- КУпАП: актуальная редакция — https://zakon.rada.gov.ua/laws/show/8073-10 (ссылка 80731-10 даёт устаревшую редакцию 2017 г.). Срок обжалования постановления — ст. 289 (10 дней, с возможностью восстановления), а не ст. 288. Санкции ст. 210, 210-1, 211 внесены в FAQ и на /shtraf/; сумма НМДГ в гривнях (17 грн) в первоисточнике не проверена.
- Ответственность за распространение информации о местах: ст. 114-2 КК (а не 114-1), применимость к ТЦК/полиции зависит от обстоятельств — на сайте формулировка осторожная.

## Приватность

Генератор жалоб работает только в браузере; ничего не отправляется и не сохраняется. Нет аналитики, трекеров, внешних шрифтов. В `localStorage` хранится только выбор темы. Нет карт, лент и сведений о местах и времени работы ТЦК, блокпостов, полиции (ч. 1 ст. 114-1 КК Украины).
