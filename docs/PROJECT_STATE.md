## Архитектура
Node/Express, статические страницы, без БД. `content/*.json` → `scripts/build.js` → `dist/` (коммитится). `src/` — CSS/JS/PWA. Генераторы (жалобы, заявление об отстрочке, срочная заявка юристу) работают только на устройстве.

## Проверка законов (главное требование владельца)
- `content/claims.json`: ~159 утверждений с дословной цитатой и привязкой к статье/пункту; `npm run verify` скачивает свежие тексты (zakon.rada.gov.ua), проверяет цитату внутри нужного раздела, «отпечаток» раздела и дату редакции; лёгкий лайнт ссылок «п./ст.» в контенте и в `generator.js`/`zaiava.js`. Кэш `.verify-cache/` (в .gitignore). `--update-hashes` после перечитывания изменённой нормы.
- Правило: новое юридическое утверждение → сначала в `claims.json` с цитатой, потом в текст. Неподтверждённое — блок «Потребує перевірки юристом».
- Покрытие ссылок цитатами ≈ 77% (не покрыты в основном списки документов додатка 5).

## Жёсткие ограничения контента
Никаких карт/стрічок про місця, маршрути, час роботи ТЦК, блокпостів, поліції (відповідальність — ст. 114-2 КК, не 114-1; застосування залежить від обставин); никаких советов уклоняться/подделывать/взятки/сопротивление; нейтральный тон; без трекеров и внешних шрифтов; дисклеймер «довідкова інформація, а не юридична консультація», джерела й «Перевірено» на страницах; весь сайт по-украински, README по-русски.
